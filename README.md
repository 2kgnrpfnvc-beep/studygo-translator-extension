# StudyGo Practice Helper

A Manifest V3 extension for Opera GX that **automatically fills in StudyGo practice answers** from your word list.

## Install in Opera GX

1. Download the repository as ZIP
2. Open `opera://extensions`
3. Enable **Developer mode**
4. Click **Load unpacked** and select this folder
5. Done!

## How to use

1. Go to StudyGo and copy your word list using `copy(document.body.innerText)` in the console
2. Click the **StudyGo Practice Helper** icon
3. Paste the word list and click **Save word list**
4. Refresh your StudyGo practice page
5. Text boxes will **automatically fill** with the correct translations

The extension stores your word list locally and matches words on the page to fill in answers automatically.
